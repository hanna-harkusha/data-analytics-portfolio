# Marketing Performance Dashboard (Tableau)
### Objective:

To build an interactive Tableau dashboard for analyzing marketing performance across advertising networks, countries, platforms, and user segments.

The goal was to evaluate advertising efficiency, monitor acquisition costs and return on ad spend, analyze the conversion funnel, and identify differences in performance across marketing channels.

### Tools & Methods:

* Tableau Public – dashboard creation and data visualization
* Calculated Fields – calculation of marketing and conversion metrics
* Filters – interactive filtering by date, country, platform, gender, age group, and advertising network
* KPI Cards – summary of key marketing performance indicators
* Bar Charts – comparison of ROAS across advertising networks
* Line Charts – analysis of ROAS dynamics over time
* Map Visualization – geographic analysis of revenue
* Funnel Visualization – analysis of user conversion from impressions to purchases
* Dashboard Layout – structured overview of acquisition and revenue performance

### Data Description:

The dataset contains marketing campaign performance data across different advertising networks and user segments.

Main dimensions used:

* Date
* Country
* Platform
* Advertising network
* Gender
* Age group

Main measures used:

* Impressions
* Clicks
* Installs
* Purchases
* Advertising spend
* Revenue

### Dashboard Metrics:

The dashboard includes the following key marketing metrics:

* Revenue
* Spend
* ROAS (Return on Ad Spend)
* CPM (Cost per Mille)
* CPC (Cost per Click)
* CPI (Cost per Install)
* CPA (Cost per Acquisition)
* Install-to-Purchase Conversion Rate

### Results:

* Built an interactive Tableau dashboard for monitoring marketing performance and advertising efficiency
* Created calculated fields for ROAS, CPM, CPC, CPI, CPA, and conversion rate metrics
* Compared ROAS across advertising networks to identify differences in channel performance
* Visualized monthly ROAS dynamics to track changes in advertising efficiency over time
* Analyzed revenue distribution across countries using a geographic map
* Built a conversion funnel from impressions to clicks, installs, and purchases
* Added interactive filters for country, platform, gender, age group, advertising network, and date
* Combined acquisition cost, revenue, conversion, and channel performance metrics in a single dashboard
